# Plan de classe

Une petite app web pour aider une enseignante de 1P-2P à répartir ses élèves aux tables : mélange des degrés, répartition des enfants qui demandent beaucoup d'attention, paires à séparer et changement de voisins d'un plan à l'autre.

**Utiliser l'app : https://andant89.github.io/app-plan-de-classe/**

L'app tient dans un seul fichier, [`index.html`](index.html) : il suffit de l'ouvrir dans un navigateur. Les données restent dans le navigateur de l'appareil.

- Cadrage de l'idée : [`docs/cadrage.md`](docs/cadrage.md)
- Cahier des charges : [`docs/cahier-des-charges.md`](docs/cahier-des-charges.md)
- User stories : [`docs/user-stories.md`](docs/user-stories.md)
- Règles des étiquettes et des versions : [`docs/etiquettes.md`](docs/etiquettes.md)
- Parcours de non-régression : [`docs/non-regression.md`](docs/non-regression.md)
- Consignes pour Claude : [`CLAUDE.md`](CLAUDE.md)

## User stories et incidents

Les fonctions sont décrites en **user stories numérotées** : l'issue #5 est la story `US-05`. Chaque critère d'acceptation a son numéro (`US-05.3`).

- Un critère échoue : ouvre un **Incident** et indique son numéro.
- Une idée : ouvre une **Demande**.
- Un travail hors fonction (documentation, mise en ligne…) : ouvre une **Tâche**.
