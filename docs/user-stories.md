# User stories de Plan de classe

Chaque user story a un numéro (`US-01`, `US-02`…) et chaque critère d'acceptation aussi (`US-01.1`, `US-01.2`…). Pour signaler un problème, il suffit de donner le numéro du critère qui ne fonctionne pas : par exemple « `US-05.3` a échoué ».

Sur GitHub, l'issue n° X correspond à la story US-X. Ce fichier est la liste de référence ; les cases se cochent dans les issues.
